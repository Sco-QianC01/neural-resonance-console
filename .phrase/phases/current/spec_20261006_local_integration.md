# 音療主啟動與神經共振控制台整合
日期：2026-10-06
## 使用者要求
啟動本地音療系統後，既有後台正常啟動，前端自動接收所有已接入的生理資料。
## 設計
- 保留澳門版統一啟動/停止入口，在清單加入獨立控制台，預設背景啟動主服務與 Node。
- 本機同源 WebSocket 只代理到現有 localhost:8002；開頁即連線，斷線退避重試，手動停止有效。
- 顯示 EEG 頻段、原生專注/放鬆、USB 比值、血氧、脈率、HRV、GSR 與其他已到達的 EEG 欄位。
- 顯示各清單程序/端口和主服務工作執行緒；程序存在不等於資料有效，過期顯示空值。
- 讀取介面不自動建立研究會話、不變更原 Max/OSC/手機傳輸/報告路由。
- 控制台 process ownership 以 Node 路徑和直接 serve.mjs 參數共同驗證，拒絕佔用埠。
## 執行與驗收
1. 備份清單、啟停腳本、主服务狀態與依賴檔。
2. 更新啟停登記、控制台唯讀橋接和全部生理欄位。
3. 單元驗證缺值/过期/斷線；PowerShell 解析和狹義 process ownership 驗證。
4. 真實啟動主服務+控制台，瀏覽器驗證自動連線、無設備等待狀態、後台程序顯示。
5. 檢查既有元件啟動鏈；可啟動者實測，未完成設備/UI/音訊驗收的逐項列明。
6. 更新文檔及私有 GitHub 源碼；受試資料和本地備份不提交。
