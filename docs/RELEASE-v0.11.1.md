# v0.11.1 · 数据完整性与兼容性复检

保留v0.11界面与课件方案。本次修复数据、连接和启动流程，不增加展示功能。

- 同一浏览器接收批次的全部原始脑电帧合并交付，保留各字段原始时间。
- 记录及CSV保留血氧、脉率、HRV、GSR；回放保留源类型和字段年龄，记录不受输入对象后续修改影响。
- 字段过期与异常未来时间戳不影响后续有效数据；传感器计数按会话重新判断。
- USB/BLE重连隔离旧字段和迟到通知；配置保存串行处理，已打开的WebSocket在流重建后立即恢复原始样本。
- WebSocket握手无响应时自动超时恢复；权限选择器尚未结束时按停止，不会在选择返回后重新开启设备。
- 已保存的USB身份在设备拔出时保留；无数据时保留最后轨迹。
- Windows源码及应用启动改用明确进程调用，兼容不完整PATHEXT；Mac启动器传递实际参数。
- 增加跨平台运行时、三浏览器、源码启动和原生包的隔离验收。兼容范围见[环境说明](COMPATIBILITY.md)。
