# v0.11.6 · 采集时序、蠕虫显示与本地音乐语言

本版更新公开源码、静态网页和分发源码的完整性。原生Windows／Mac发行包须由对应系统构建并通过验收后另行发布；源码版本更新不表示下载页旧应用已自动升级。

- 音乐、神经与对照图使用各自坐标；二维、三维时间轨迹与高级分析分层，改进线条、当前点和窄屏显示。
- 采集使用单调时钟判断新鲜度和顺序；关注／放松只有来自同一报告时才配对。记录保留原始时间、来源、断点和单项读数，非有限值不进入数据流。
- 可选Android手表前台心率采集与EEG来源独立；只有有效且新鲜的传感器事件才计入当前测量。采集端源码及构建说明见[手表说明](WATCH.md)。
- 独立音乐提示词工具运行在8771，Ollama使用单独的本机端口；支持观测JSON、人工创作档位、规则预览及受约束的qwen3:4b标签编排。模型不接收原始生理数据。详见[音乐提示词](MUSIC-PROMPT.md)及[隔离运行](MUSIC-PROMPT-RUNTIME.md)。
- 编排校验冲突档位、完整结束、模型身份和标签全排列；输入变化可取消，缓存明确标注复用，BPM与时长按当前目标重新编译。
- 新保存的完整JSON可重新导入并恢复支持的原始观测、缺失断点、单位和目标，旧AI输出不自动沿用；迟到的文件或参考标注不会覆盖更新输入。输入摘要包含原始样本顺序。
- 修复源码ZIP漏掉手表及提示词模块的问题。新增对实际ZIP解压产物的导入、音乐提示词测试和静态构建检查，避免完整仓库通过而下载包启动失败。
- 修复极端正数速度比值溢出：相邻变化改用等价的对数差，避免有效输入在JSON中变成无说明的null。
- 浏览器回归明确选择神经主画布并核对非空样本时间，适配双画布布局，继续验证断流停止、重连及回放；记录验收有界等待实际样本数，失败工件保留样本诊断和异常堆栈。
- 原生发布说明按发行标签选择，避免未来版本继续引用v0.11.4说明。

源码安装仍使用项目独立依赖，不关闭macOS系统保护，也不复制作者运行环境。ADB和本地Ollama属于各自可选模块的前置工具；源码ZIP不包含设备配置、个人记录、模型权重、实例身份或测试签名。

软件协议、模拟事件、CI及浏览器检查不能替代实体设备精度与Mac首次权限验收。尚未验证生理到音乐标签映射的效度、临床效果、所有设备兼容性或24小时连续运行；音乐生成与听辨另行进行。
