# 设备协议与验证状态

| 设备类型 | 入口 | 支持范围 | 本轮验证 |
| --- | --- | --- | --- |
| ThinkGear相容脑电 | USB/串口 | 0xAA帧、校验、原始ADC、质量、原生指数、8频段装置功率 | 协议、变号、断流、重连隔离的受控测试；实机采集单独验收 |
| ThinkGear相容脑电 | BLE | 按名称或保存地址／Mac UUID匹配；支持指定服务和特征UUID | 协议、身份和迟到通知隔离测试；实机权限和采集单独验收 |
| AFE4490文本板 | USB/CH340 | `Sp02 : 98% ,Pulse rate :72 bpm`及SpO2拼法 | 文本、无效探头过滤及字段时间测试；实机采集单独验收 |
| GSR文本设备 | USB/串口 | 数字行或`GSR: 450`，明确配置VID/PID后启用 | 解析测试通过；默认禁用，未接实际GSR |
| 其他厂商 | WebSocket网关 | 标准JSON数据合同 | 前端格式/过期检查通过；厂商协议需另加适配器 |
| HRV | 外部网关 | 必须提供真正的RR/HRV来源字段 | 没有RR时保持缺失，脉率不当成HRV |

独立默认配置没有固定USB序列号：一台唯一匹配的设备会自动选择，多台同型号设备可在设备设置页按序列号/USB位置选择。没有唯一身份时等待，不任意打开串口。

Windows使用COM名；macOS使用`/dev/cu.*`，选择逻辑按VID/PID及可选身份，与端口名称无关。同一Mac端口同时出现cu/tty别名时优先cu，不误认为两台设备。macOS蓝牙设备地址可能为UUID，代码将其作为平台身份保留，不伪造成MAC。

插拔轮询每秒进行，已授权、唯一匹配且使用所支持协议的设备自动连接。第一次系统蓝牙权限、数据线、驱动、串口占用、设备电源与电极接触仍须满足。设备页自动更新枚举与诊断，并保留未保存的人工选择。无数据、协议不匹配、权限不足和同型号歧义分开显示；不使用合成示范替代采集失败。

标准ThinkGear指数按原生0–100保存，值0视为暂不可用；装置功率和原始ADC保留各自量尺。原始ADC未标定为µV。名义采样率可配置，不把接口心跳频率当成设备采样率。

设备枚举路径、变号、重连使用受控设备模拟。原生包启动、源环境兼容、真实USB/BLE采集分别验收；自动化测试不能替代实机结果。环境矩阵见[环境与验收范围](COMPATIBILITY.md)。
