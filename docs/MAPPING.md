# EEG → 音樂映射

版本：`eeg-music-rules-v2`。十大音樂要素對應旋律、節奏、和聲、力度、
速度、調式、曲式、織體、音色、演奏法。此規則可由後續模型替換。

令 `a = attention / 100`、`r = relaxation / 100`、
`energy = 0.65 × a + 0.35 × (1 − r)`：

| 要素 | 控制規則 |
|---|---|
| 旋律 | round(48 + 24a)，中心音高 MIDI |
| 節奏 | 1 + 8a，事件／小節 |
| 和聲 | round(10 + 55(1 − r))，張力 % |
| 力度 | round(32 + 58(0.45a + 0.55(1 − r)))，MIDI velocity |
| 速度 | round(bpmMin + (bpmMax − bpmMin)energy)，BPM |
| 調式 | round(20 + 60r)，明亮傾向 % |
| 曲式 | round(8 + 24r)，樂句秒數 |
| 織體 | round(1 + 5energy)，聲部數 |
| 音色 | round(15 + 70energy)，明亮度 % |
| 演奏法 | round(30 + 60r)，延音比例 % |

只有有效的 0–100 設備指數才輸出控制量。USB 頻段比值不直接轉成 0–100。
二維軌跡使用 `(a, 1 − r)`，與其他顯示共享同一份有效輸入。
這是可修改的交互規則，不是已驗證的情緒或生理效果模型。

聲音預覽由使用者主動開啟，採低音量正弦波；資料失效後靜音。
模型生成音樂是另一項工作，本頁不呼叫音樂模型。

神經網的密集度、離散度及記錄格式見 [神經蠕蟲網](NEURAL-WORM.md)。
