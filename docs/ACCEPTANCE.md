# 驗收

```sh
npm test
npm run build
```

檢查三個介面：

1. 首頁四頻段動態示範立即可見，不探測私人接口。
2. 切換神經蠕蟲，資料計數繼續；軌跡採收到的樣本。
3. 十要素可切換課件創作方案與音樂觀測。前者保留選擇方式及來源頁碼，後者需來源、方法、單位及匹配時間；沒有觀測的項目不顯示。
4. 設備頁區分瀏覽器能力與已建立的硬體連線。
5. 記錄後可下载JSON／CSV、回放、匯入／匯出設定。
6. 實時來源停止計數時不繼續游走，不自動生成替代資料。
7. 三個手機介面沒有橫向溢出；減少動效時停止非資料動畫。
8. 公共靜態網站不自行配對或選擇设备；本機采集器啟動後依已配置身份自動連接。上傳需使用者主動操作。
9. 三個入口在左側；手機上可開啟左側導航。展示模式保留等比例XY坐標，Esc可返回。
10. 記錄、JSON、CSV與回放保留創作方案；回放不會被目前選擇器覆寫。匯入規則未覆蓋的位置不套用隨機方案。

USB／BLE 實機與真實遠端保存需另外驗收；協議測試流不能替代實機證據。
