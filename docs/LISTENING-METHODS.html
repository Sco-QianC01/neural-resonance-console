音樂與神經響應：聆聽實驗方法

依據與流程

本工作台將采集核查、音樂參考、神經響應與版本實驗分步組織。設備指數與音樂標注保持獨立，配對統計用於探索性描述。

現在的流程為：設備設定→音樂參考→神經響應→版本實驗。波形捕獲供原始信號檢查。音樂庫和演奏者、年份、拍點、拍值及相對振幅沿用Vmus來源；音訊原速，不加入雙耳拍或額外頻率。先看原始拍點／速度曲線，其他已提供的音樂觀測可獨立查看。

時間方盒

每個有效點為同一樣本的關注A、放鬆M、時間t。平面坐標保留原生0–100指數；時間z=(t−t₀)/1000，單位秒。觀察尺度只改變顯示窗口，正交旋轉只改變投影，不更改數值、時間或資料。原始索引更新時鐘與振幅時鐘分開。

振幅仍使用去均值RMS與原單位編碼光點明暗，沒有電壓標定時保留ADC counts。時間深度不表示振幅、物理穿透、神經傳播或量子維度；缺口按來源段落斷開。

關注和放鬆保留兩個來源字段，不能以100−關注補成放鬆。頻段功率不能為迎合「反方向」而任意翻轉；任何頻段映射與校準係數都需要設備標定與驗證依據。

三個版本

只從同作品、有明確年份的完整研究版本中選擇三項。Op.27 No.2默認使用核查過的1978、1981、2003版本，顯示實際年份，不聲稱必定間隔50年。其他作品依可用版本選擇，同作品其他版本及原站片段仍可從音樂庫選取。

每次手動開始，音訊原速播放，預設記錄60秒，可選30或120秒或提前結束。中途暫停或切換播放來源會結束試次；更換設備身份、無效接觸、斷流、示範和回放不加入有效指數分析。試次內同設備來源的原始封包先保留，包括指數重複、缺失或接觸不良但有新波形的包；指數依來源字段時間去重。同字段的原始波形新增封包不會冒充新的指數點。音樂值按補償後media time再次查詢標注，不把封包到達時的音樂值配給更早的指數時間。

配對時鐘

media time = HTMLMediaElement.currentTime − (packet arrival time − index field time)/1000

若來源没有字段時鐘，使用封包到達時刻並保留這一限制。僅接受試次開始後且不在未來的有效資料。這不是聲卡輸出時刻校準，沒有耳機端音訊時間戳或設備時鐘校準時，不宣稱毫秒級刺激同步。

音樂小節來自原始拍點；各版本相同秒數不能當作相同小節。同時相关對應本次聆聽者與本版本實際播放，不將不同演奏版本直接按秒合併。

小節編號為整數，空間圖每小節一個平面層；同小節的逐拍觀測位於同一層，跨小節以虛線表示推進，缺失不連接。默認顯示鄰近8層，可切換16層或全曲；點選層號可定位播放，當前層高亮。音樂空間保留各層坐標，去除封閉立方體外框。

小節內連續位置另存為 barPosition；beatInBar 為從0開始的來源拍點索引，beatsPerBar 為來源標注的每小節拍數。全曲速度曲線用連續拍位保留原始時序，軸標籤仍只顯示整數。這些字段不互相替代，也不把分數拍位寫成小節編號。

可復算統計

μ = Σx/n

樣本標準差 s = √[Σ(x−μ)²/(n−1)]

Pearson r = Σ[(x−μx)(y−μy)] / √[Σ(x−μx)²Σ(y−μy)²]

每版列出指數有效點數、均值、樣本標準差，以及原始速度／相對振幅與關注／放鬆的同時相关。音樂標注缺失處不補值，r採完整配對；少於3對或任一變量零方差時留空。服務端保存時從逐行數值重新計算，不信任頁面提供的統計。

上述r未控制時間自相關、眼動／肌電偽跡、基線、次序效應及時滯，也不給出把相鄰採樣點當獨立實驗單位的顯著性或置信區間。它是探索性描述，不能單靠r證明耦合、因果、審美同質、自主神經狀態或臨床療效。

線性、離散觀測與相對振幅

音樂空間以整數小節分層，速度與連續的來源相對振幅為層內坐標；腦電時間圖使用秒軸。音符時值、坐標分辨率與統計層數不是離散性的同義量。

速度曲線始終保留原始人工拍點。取消高斯窗可見逐拍階梯；高斯窗只是一條顯示曲線，不消除原始點。速度結構方盒另提供兩個可復算的探索性代理：最近最多8個有效原始拍速度對譜面小節做OLS線性擬合，輸出 linearityProxyR2；相鄰原始拍速度變幅輸出 changeProxyLog2 = |log₂(vᵢ/vᵢ₋₁)|。少於3拍留空，常量段顯示「恆定段」。這兩個代理尚未形成固定的線性度／離散度公式，也與標準差、變異係數或音符時值跳變不是同一量，未冒稱已測音符由全音符跳至64分音符。

這兩個代理是本次研究的初步操作定義，用來比較漸進變化與相鄰突變，不是已驗證的審美或神經指標。「審美係數」仍不自動生成。原始波形上下方向與音樂特徵—神經指標的正/負/不足關係另行记录，二者不互相替代。

相對振幅直接採用原站 amp.v 與 dt 網格內線性插值，保留連續來源0–100標度；原站注明這是2007年程序計算的平滑振幅。未取得可復算的聲壓／響度校準，不能標作百分比、dBFS、dB SPL、LUFS或跨錄音的絕對響度。譜面力度符號p、pp、mp、mf、f、ff與fp等需有明確譜面或人工標注來源；本站不從振幅分箱推定這些符號，也不建立一個稱為N的中間力度檔。

新試次JSON與CSV保留 level、levelSource=vmus-2007-smoothed-amplitude、levelUnit=source-relative-0-100；缺少譜面標注時 dynamicMark 留空。舊 dynamicTier 相關欄位僅作格式兼容，新試次均留空。原有文件不被覆寫；音訊、來源振幅與播放增益保持分離。

原始波形與頻段

原始ADC是有符號的16-bit來源值；以零為中線保留負向波。按rawSequence去除重複或重叠，缺失處斷開，像素分箱保留最小／最大值。自動縱軸只擴大不在連續來源中反覆縮小，亦可手動指定±範圍；px/單位是顯示倍率，不是電壓增益。微小數值按來源單位呈現，沒有硬件標定不寫成微伏。

ThinkGear八頻段功率各自保留，缺失不補0。原始功率非負。基線偏移視圖為power−當前60秒窗口最早最多10個有效值均值，負值表示低於基線，不表示負功率或神經抑制。欄位時間相同的重複封包不當新頻段觀測。gateway每100ms傳輸可用資料，原生指數更新頻率仍由設備決定；不為「敏感」虛造新指數。

核查音樂副本

傅聰1978、巴倫博伊姆1981、郎朗2003（Op.27 No.2各463個人工拍邊界）及李雲迪2004（Op.9 No.2，141邊界）全段解碼，拍點與相對振幅覆蓋區間核查通過。本機研究副本放在用戶結果目錄，離線播放；其他安裝環境沒有副本時回到原站串流。原站副本48kbps，不能稱為無損或經人工證實無噪聲。峰值統計不等同噪聲測量。播放器固定0.5增益（−6.02dB）為解碼峰值保留余量，不改分析数据或音乐速度。

帕赫曼1925因用戶指出底噪而移出默認演示，保留歷史來源。研究副本保留原始SHA256與來源，未公開發佈或再授權錄音。

保存及邊界

保存到新的本機結果文件夾，包括experiment.json（全部原始封包、配對行、版本來源和方法）、paired.csv（UTF-8 BOM，Excel可讀）、figure.png（當前觀測視圖）和report.html。不覆寫已有試次；寫入失敗保留頁面資料以重試。

本機Windows若指定Q盤結果目錄存在，使用用戶授權的music-therapy-pod-sensors/results。其他電腦使用本機應用資料目录下results；明確隔離的NEURAL_RESONANCE_DATA運行保存到其自己的results。錄音及私有轉寫不進安裝包。

沒有接入實體設備時，頁面可以演示和查看音乐，但不會生成真實聆聽試次。USB/BLE電極品質、Mac實機、實體拓展屏幕、耳機聲音與延遲需物理驗證。
