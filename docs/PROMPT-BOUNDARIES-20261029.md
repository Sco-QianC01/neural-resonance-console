# 数据标注边界修复

本轮继续检查第四板块的数字输入、观测统计和保存交接；设备、波形、蠕虫及其保护基线未修改。

## 已复现并修复

- **未完成数字仍能导出。** 在目标速度依次输入 `-` 或 `1e`，浏览器的值是空字符串，但 `validity.badInput` 为真。旧代码将其当作未指定；现在明确报错并禁止导出。主动清空仍可正常生成。
- **极小正数统计下溢。** `[1e-200, 2e-200, 3e-200]` 原来得到零SD／CV；次正规数的均值舍入还会污染CV。现在在最大样本缩放域计算总体均值、SD和CV，最后还原均值与SD的单位；统计定义和分母N不变。极小值仅用于数值回归，不代表现实音乐速度。
- **稀疏数组绕过校验。** 函数调用中的 `[60, , 120]` 原来会生成非有限的相邻变化值。现在拒绝空洞与未定义值；JSON或函数调用的缺失均须显式为 `null`，相邻变化不跨缺失。
