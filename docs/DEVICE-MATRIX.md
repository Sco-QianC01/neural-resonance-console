# 设备协议与验证状态

| 设备类型 | 入口 | 支持范围 | 本轮验证 |
| --- | --- | --- | --- |
| ThinkGear相容脑电 | USB/串口 | 0xAA帧、校验、原始ADC、质量、原生指数、8频段装置功率 | 协议/变号/断流测试通过；本机设备可识别，但目前无持续字节 |
| ThinkGear相容脑电 | BLE | 匹配名称后订阅通知；支持指定服务和特征UUID | 协议与USB共用；真实BLE连接待验证 |
| AFE4490文本板 | USB/CH340 | `Sp02 : 98% ,Pulse rate :72 bpm`及SpO2拼法 | 文本及无效探头过滤通过；本机有字节，尚无有效探头值 |
| GSR文本设备 | USB/串口 | 数字行或`GSR: 450`，明确配置VID/PID后启用 | 解析测试通过；默认禁用，未接实际GSR |
| 其他厂商 | WebSocket网关 | 标准JSON数据合同 | 前端格式/过期检查通过；厂商协议需另加适配器 |
| HRV | 外部网关 | 必须提供真正的RR/HRV来源字段 | 没有RR时保持缺失，脉率不当成HRV |

独立默认配置没有固定USB序列号：一台唯一匹配的设备会自动选择，多台同型号设备可在设备设置页按序列号/USB位置选择。没有唯一身份时等待，不任意打开串口。

Windows使用COM名；macOS使用`/dev/cu.*`，选择逻辑按VID/PID及可选身份，与端口名称无关。macOS蓝牙设备地址可能为UUID，代码将其作为平台身份保留，不伪造成MAC。

标准ThinkGear指数按原生0–100保存，值0视为暂不可用；装置功率和原始ADC保留各自量尺。原始ADC未标定为µV。名义采样率可配置，不把接口心跳频率当成设备采样率。

Windows本地运行已检查。macOS的设备枚举路径及重连使用受控假设备测试；原生应用构建和真实Mac USB/BLE采集另行标明，不能由假设备测试推出“所有设备已正常”。
