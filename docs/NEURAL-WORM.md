# 神經蠕蟲：可追溯的雙指數時間軌跡

版本：`evidence-trace-v3`、`music-observation-panels-v3`。

原演奏蠕蟲研究使用音樂速度與響度；本頁只移植雙參數時間軌跡的顯示方法，
坐標為設備原生專注與冥想／放鬆指數。這個移植沒有證明EEG可以決定音樂偏好。

預設原始0–100坐標，可選0–127顯示換算。每點保留時間、來源、品質及記錄識別。
缺失、接觸不良或連接epoch切換時斷開；恒定輸入不自行游走。
可選平滑僅影響顯示，原始點與記錄不變。點選或拖動時間滑桿可核對同時刻的讀數。

十要素切換課件來源創作方案或帶來源音樂分析。所有層共用當前選定時間；創作意圖不冒充設備測量。
缺少音樂觀測時收起該項。沒有預置腦區網形；等比例畫布不拉伸時間軌跡。

標準距離、覆蓋時間及來源的逐項核對見[EVIDENCE.md](EVIDENCE.md)。

左側三頁、展示模式及十要素方案見[MUSIC-PLANS.md](MUSIC-PLANS.md)。
