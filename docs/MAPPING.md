# 音樂觀測與證據要求

版本：`music-evidence-v3`。v0.10撤下`eeg-music-rules-v2`的十項推算公式。

`mapMusic`只接受同時刻且包含記錄識別、分析方法、單位和來源URI的音樂觀測。
專注／冥想指數本身不能產生音高、BPM、張力、調式、曲式、音色或演奏法。
未觀測項為null；`controls127`也為null，不正規化出新的音樂控制量。

十項名稱是專案標注分組。音訊／MIDI分析、樂譜或人工標注需保留來源；
僅標明來源不代表方法已被獨立驗證。和聲、調式等使用文字標注，
不生成自設百分比。音樂響度與MIDI力度不混用單位。

完整契約、來源與適用邊界見[EVIDENCE.md](EVIDENCE.md)。
