# 神經蠕蟲：雙參數軌跡與十項音樂組織

版本：`neural-worm-trace-v2`、`neural-worm-network-v2`。

## 理論來源與適用範圍

演奏蠕蟲把兩個連續音樂參數放在平面上，頭部表示當下數值，軌跡的明暗、大小及順序表示時間。Dixon 的演奏分析及 Air Worm 使用速度與力度；Vmus 的楊健研究資料也呈現速度—力度—時間，部分視圖交換兩個座標軸。座標方向需明示，不能只靠動畫外觀推斷。

本工具沿用「雙參數隨時間運行」的方法，將輸入改為設備原生專注／放鬆指數，並加入可替換的音樂控制規則。這是技術上的交互移植，並非文獻已驗證「這兩個指數能決定十項音樂偏好」。

使用者提供的音樂資料包含情緒環形模型。該模型的效價／喚醒度與本工具的專注／放鬆指數不是同一組測量；本頁保留原生名稱，不自動標記快樂、悲傷、恐懼或臨床狀態。

## 操作

1. 選擇明確標記的示範、實時或回放來源。
2. 主圖預設 XY 控制座標 `0–127`，中心十字位於 `64,64`。
3. 可切換原生 `0–100` 或映射的速度／力度。
4. 觀察窗口可選 10、30、60 秒；因果平滑可選 0、0.75、2 秒。
5. 點選軌跡或拖動時間滑桿查看過去節點，十項控制層同步切到同一時刻；勾選「跟隨最新」返回即時位置。
6. 點選十個網，主圖顯示該音樂組織層；可保存目前畫面 PNG。
7. 手動產生創作提示詞，或開啟「每 60 秒整理一次」，再主動複製／匯出。這一步不呼叫或上傳雲端模型。

## 共用座標和時間

```text
x127 = round(attention / 100 × 127)
y127 = round(relaxation / 100 × 127)
```

因此原生 50 對應控制 64，0／100 對應 0／127。控制座標採 7 位整數習慣；連續數學中點是 63.5，畫面採最接近的整數 64。原生資料與記錄不被改寫。

主圖只增加真實收到且有效的樣本。無效接觸、間隔超過 3 秒、來源／session／transport／epoch 變更時斷開，不跨段補線。重複時間戳、未前進的硬體封包數、未來資料與越界指數不生成新節點。

起點為空心圈，末點為亮點。線寬和明度從舊到新遞增。動畫時鐘僅控制光效，不改變測量位置或控制網幾何。恒定輸入停在同一位置；暫停／斷流後光效停止，保留最後有效觀察。

## 顯示平滑

只使用當前樣本以前、同一連續段內的資料，使用高斯權重：

```text
sigma = smoothingSeconds / 2
w(t) = exp(−0.5 × (age / sigma)²)
```

支持範圍為 3σ；按時間支持長度加權，降低不均勻收包密度的影響。它是本專案的因果顯示實作，不冒充 Vmus 離線雙側高斯算法。原始樣本、記錄、窗口統計及音樂控制量保持未平滑值。

## 軌跡密集度與離散度

統計先在有效、連續、實際觀察的折線段上，以 250ms 等時間間距評估位置。只用於統計，不向記錄或螢幕增加測量樣本，不跨缺失段內插。

- **軌跡密集度**：所有統計點對中，正規化 XY 距離 ≤0.10 的比例。
- **軌跡離散度**：點雲距質心的均方根半徑，除以 √0.5，再限制到 0–1。
- **有效觀察秒數**：有效連續段時間之和；觀察窗口 60 秒不代表實際收到完整 60 秒。
- **變化量**：首尾原生專注、放鬆的差；只描述指數變化，不診斷情緒。

恒定資料的密集度為 1、離散度為 0；單一點無足夠點對，顯示缺失。兩者是明確定義的視覺／幾何統計，沒有通用的「健康」閾值。

## 十項音樂要素

順序依使用者提供的音樂理論資料：

| 要素 | 單位控制量 | 組織層 |
|---|---|---|
| 旋律 | 中心音高 MIDI | 單一／多動機、旋律轉折 |
| 節奏 | 事件／小節 | 疏落／密集、節奏變化 |
| 和聲 | 張力控制 | 穩定／較多和聲變化 |
| 力度 | MIDI velocity | 平穩／明顯力度對比 |
| 速度 | BPM | 穩定脈動／速度變化 |
| 調式 | 明亮傾向 | 單一／較多調式色彩 |
| 曲式 | 樂句秒數 | 重複／較多段落發展 |
| 織體 | 聲部數 | 少聲部／分層聲部 |
| 音色 | 明亮度 | 集中／多音色組合 |
| 演奏法 | 延音比例 | 統一／較多演奏法對比 |

高音高、快 BPM 或較長樂句不直接等於複雜。保留既有 `eeg-music-rules-v2` 單位控制量，另列兩條明示的**實驗組織規則**：

```text
complexity127 = round(attention / 100 × 127)
dispersion127 = round((1 − relaxation / 100) × 127)
ruleVersion = organization-xy-v1
```

這個方向是為可操作的交互實驗設定，並非老師已提供的完整標注標準或文獻已證明的生理推斷。後續標注和模型可以替換規則，不能把未校準的關係寫成科學定論。

十個網各自使用序列、脈衝、和弦群、力度弧線、速度軌道、調式環、樂句組、平行聲部、音色輻射、演奏連線等不同幾何。它們共享同一輸入時刻。

網密集度直接由生成圖計算：`2E / N(N−1)`。網離散度同樣用節點 XY 的均方根半徑除以 √0.5。這是**音樂組織控制網**，不是 EEG 測得的腦區連通圖。

## 匯出和後續模型

記錄保留原生輸入、來源、時間、品質、十網狀態及版本。提示詞 JSON 另外包含觀察覆蓋秒數、軌跡統計、十項單位控制、0–127 控制和簡單／複雜描述。

60 秒整理開關只生成本地交接內容；無有效指數時不生成。有缺失時保留實際覆蓋時間，不自動補成完整觀察。目標模型選擇只表示手動交接對象，不宣稱這個頁面部署了生成模型。
