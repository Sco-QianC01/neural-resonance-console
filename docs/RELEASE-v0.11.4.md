# v0.11.4 · 独立部署与跨平台修正

包含截至 2026-10-16 的音乐与神经蠕虫、原始波形、肖邦资料和乐谱证据修正。

- GitHub 干净源码包含离线测试所需的公开资料，不再读取作者临时文件。
- Windows 检出保留乐谱 LF 字节，来源 SHA256 校验不受换行转换影响。
- Windows 与 macOS 启动器拒绝继承系统包的环境，保留不兼容旧环境并重建私有依赖。
- Windows 中文实验目录名不依赖系统日期格式化编码；新记录保存于本用户数据目录的 `results`。
- 修正 WebKit 音乐选择控件的窄屏溢出，保留全部选项。
- Mac ARM64 与 Intel 的源码启动、离线搬迁、重复启动、端口冲突和重启纳入持续回归；原生包在对应系统构建并执行启动与搬迁验收。

下载对应系统架构的完整 ZIP 并解压。Windows 双击 `NeuralResonance.exe`；Mac 打开完整 `Neural Resonance.app`。源码方式见[跨平台部署](PORTABLE-DEPLOYMENT.md)。原生包不需要另外安装 Python 或 Node。

首次蓝牙权限、未签名 Mac 应用的系统允许打开操作及厂商驱动仍由操作系统处理。支持的是[设备矩阵](DEVICE-MATRIX.md)列出的协议；CI 禁用硬件，不能替代实体 EEG/BLE、数据线、电极和 Mac 首次授权验收。音乐串流需要网络，私有音频与个人采集数据不包含在发行包。
