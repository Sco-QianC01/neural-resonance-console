# 神經蠕蟲網

本頁是獨立的腦波 → 光粒子神經網 → 音樂控制介面。
沒有食物、得分或遊戲目標。十個網各自對應一項音樂要素，可點選展開。

## 十大要素

依提供的《吉利用户界面前端》資料第 16 頁整理：

旋律、節奏、和聲、力度、速度、調式、曲式、織體、音色、演奏法。
定義與順序保存在 `src/music.mjs` 的 `ELEMENTS`，
本頁不把空間寬度或過渡時間當作十大基本要素。

## 音樂控制量

目前使用可修改的規則 `eeg-music-rules-v2`，以有效設備指數為輸入。
它是交互實驗規則，不是訓練模型或情緒診斷：

| 要素 | 控制量 |
|---|---|
| 旋律 | 中心音高，48–72 MIDI |
| 節奏 | 事件密度，1–9 / 小節 |
| 和聲 | 張力控制，10–65% |
| 力度 | MIDI 力度，32–90 |
| 速度 | 48–108 BPM，控制台可改範圍 |
| 調式 | 明亮傾向控制，20–80%；不是自動判定大／小調 |
| 曲式 | 樂句長度，8–32 秒；不是完整曲式識別 |
| 織體 | 聲部數控制，1–6 |
| 音色 | 明亮度控制，15–85% |
| 演奏法 | 延音比例控制，30–90% |

## 密集度與離散度

每個網以自身控制量正規化得到 `level`（0–1）。
放鬆指數除以 100 為 `r`：

```text
density = 0.18 + 0.68 × level
dispersion = clamp(0.75 − 0.48 × r + 0.12 × (1 − level), 0, 1)
nodeCount = round(28 + 40 × density)
```

密集度控制節點數及連線半徑；離散度控制節點分布的展開程度。
兩者為視覺控制參數，不是實測的腦區連通性。
固定節點種子、相同輸入和相同動畫時刻會產生相同拓撲。

來源無效、計數停止或手動暫停時，停止粒子移動並淡化最後畫面。
設備的 β/α、θ/α 比值仍保留比值語義；没有設備 0–100 指數時不生成此頁的網路映射。
若要用比值或其他 EEG 特徵，需在資料源提供經明確定義的映射，不能直接冒充原生指數。

## 記錄

JSON 包含原始輸入、來源、品質計數和每個網的控制量，
使用 `neural-resonance-recording-v1` 與 `neural-worm-network-v1` 版本。
資料僅在當前瀏覽器頁面保存，按匯出才下載；不自動上傳。

## 二維蠕蟲

參考 Vmus 的演奏蠕蟲可視化思路：按時間順序連接二維量值。
官方幫助：<https://v3.vmus.net/help.html?lang=zh#video>。

本工具提供兩種座標：

- EEG：X 為專注度 / 100，Y 為放鬆度 / 100。
- 音樂控制：X 為映射速度的正規化值，Y 為映射力度 / 127。

後者是由 EEG 得到的控制量，沒有分析錄音的拍點或實際演奏力度，
不能當作 Vmus 的完整音樂分析結果。
大圖的樣本位置只由輸入決定；光點脈動不生成新的測量點。
