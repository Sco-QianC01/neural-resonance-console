# 二維神經蠕蟲：資料定義、公式與證據邊界

核查日期：2026-10-11。本文對應目前二維觀測頁；不是球面調性空間或自主神經活動的驗證研究。

## 1. 圖形的研究對象

圖形呈現同一資料源隨時間提供的兩個設備指數。每個點是一筆有效觀測，尾跡依時間排列。X軸為Attention（關注指數），Y軸為Meditation（放鬆指數）；刻度保持設備的0–100原生範圍，不加百分號。

NeuroSky將eSense稱為相對1–100量表；0表示當時不能可靠計算。其基線演算法屬專有方法，並含動態適應。[1,2] 因此本頁只能說「設備指數」，不能把數值當成標準化心理量表、效價／喚醒、診斷、情緒概率或交感／副交感神經的直接測量。其他適配器若合法定義0值，按來源協議處理；ThinkGear的0值則不畫有效位置。

「神經蠕蟲」是本项目的界面名稱。將雙指數置於平面並顯示時間尾跡，是本项目的觀測布局，**不等於已驗證的生理狀態空間模型**。本文所列「關注／放鬆」「密集／松散」「和諧／緊張」可以形成後續研究假設，現有資料不能證明它們相互等價。

## 2. 位置與時間

若方形左上角為(L,T)，邊長為S，同一樣本的Attention=A、Meditation=M：

```
x = L + S · A / 100
y = T + S · (1 − M / 100)
```

兩軸每個指數單位使用相同像素尺度。視口或顯示縮放改變時重算S，方盒不被拉成長方形。點位置使用原生數值；沒有動畫時鐘驅動的漂移，振幅也不參與XY計算。

只連接相同來源／會話／連接身份的相鄰有效點；品質不良、無效指數及超過3秒的間隔斷開。時間戳重複、倒退或硬體封包計數不前進，不增加有效軌跡点。3秒是現有接口的新鮮度策略，不是生理閾值。

目前有效資料與歷史樣本分開顯示。斷流後保留尾跡，但停止有效讀數和光暈。滑動時間游標可觀察已保存樣本；「暫停觀察」只凍結界面，采集仍繼續。「暫停回放」停止記錄播放。每次啟動／恢復回放使用獨立觀察身份，重新開始當輪尾跡；原記錄的來源、會話與時間戳保留，不被覆寫。

## 3. 原始振幅

ThinkGear的RAW與EEG_POWER／eSense是不同欄位。RAW是帶符號原始樣本，設備與模組可能有不同采樣率；協議同時記載128Hz與512Hz的情況。[1] 本頁不把頻段功率、Attention或Meditation當成原始振幅，不預設所有來源都是512Hz。

取最新最多256個原始樣本，累積至少32個才顯示。令樣本為u₁…uₙ：

```
μ = (1/N) Σ uᵢ
AC RMS = sqrt[(1/N) Σ (uᵢ − μ)²]
```

這是**去直流均值的RMS幅度描述量**，不等於未去均值RMS、峰值、峰峰值、頻段功率或已分離的神經振盪幅度。運算使用Welford二階矩，保留來源單位：ADC counts仍是ADC counts；沒有硬體增益／電壓標定時不轉換為µV。來源標示采樣率時可附名義窗口長度N/fs；未標示就不聲稱固定秒數。

`rawSequence`按接口約定表示累積接收原始樣本序號。序號重複或重疊會去重；缺口及`rawDropped`清空窗口。協議校驗失敗或已知欄位長度錯誤會被完整拒收，下一個有效原始樣本以`rawBreaks`標記斷點；它與本封包樣本陣列使用從0開始的索引。斷點前後不連線，RMS只取最後一個連續片段。`quality.protocolErrors`是協議錯誤計數，不等於丟失ADC樣本數；無法知道的數量保持未知。來源、單位、采樣率或序號模式變化，品質不良與超過3秒斷流，都重建窗口。沒有原始序號的來源仍可做幅度描述，但方法欄標示「連續性未回報」，不宣稱確認了硬體采樣連續性。

空樣本封包報告丟樣或計數器前進時立即清空舊窗口，不等待3秒。計數器重啟只從新的樣本重建；空封包中的合法計數器亦保留，避免采樣率改變後把相同計數器的快取樣本當成新資料。負值、非安全整數或小於封包樣本數的計數器不能作連續性證據。

振幅使用獨立時間：來源已有`fieldTimestamps.raw`或`fieldTimestamps.rawEegSamples`時按秒轉換並檢查新鮮度；未提供時使用封包到達時間，不能稱為硬體采樣時刻。原始字段過期、倒退或超出現有接口未來容差時停用該窗口。只更新其他欄位的封包不推進振幅時間。回放保留原始振幅時間，與重播時鐘分開。

讀數使用小數或緊湊科學記號，避免小的非零振幅四捨五入顯示為0.0；例如0.005顯示為`5.00e-3`。這只改變文字格式，原始樣本、RMS數值、單位及光點映射不變。

原生ThinkGear來源只有新鮮、整數且等於0的`poor_signal`才通過接觸品質門檻；缺失、過期或格式無效顯示未確認，不當作接觸良好。指數亦須為來源規定範圍內的整數。即使供應商的poor_signal為0，也未證明消除了眨眼、肌電、心電、動作等偽跡。[1] 本頁没有ICA、獨立偽跡判別或臨床級信號验证，RMS应理解為**接收原始資料的幅度統計**。

頻段與指數圖優先使用各欄位來源時間，重複心跳不增加觀測點；接收封包時間仍保留，不能冒充硬體采樣時刻。

頻段與代理指標面板以60秒滾動窗口顯示；代理指標（參與度β/(α+θ)、相對Alpha α/(δ+θ+α+β)）由八條原生頻段按公開公式計算，缺失值斷線不補、分母為零不回傳無限大，詳見[腦波頻段與指數](BAND-INDICES.md)。

## 4. 光點的顯示規則

令R為RMS，C>0為同來源單位的顯示參照，預設C=100：

```
I = R / (R + C)
point radius = 4 + 2I               （CSS px）
halo radius = R>0 ? 7 + 19I : 0    （CSS px）
```

I單調增加並限制於[0,1)。增加R使光點白色內核及局部光暈增強；不改動位置、歷史數值、軌跡拓撲或測量維度。C是可修改的**顯示參數**，不是人群標準值、健康閾值或振幅校準。不同單位或不同參照下的明暗不能作跨人／跨設備比較。

本文所列光的「深度／穿透」在這裡只取視覺層次含義。二維投影沒有Z坐標；2026-10-13時間方盒新增的深度只表示經過秒數，不主張物理穿透深度、量子粒子、音的球面幾何或脑区传播机制。調性網絡Tonnetz及聲學頻率空間處理的是另一些變量，不能替雙指數觀測提供自主神經的因果證據。

## 5. 音樂要素與對齊

只有來源提供同時刻`music-observations-v1`資料，且值、單位、來源類型、id、uri、方法皆完整，才顯示相應要素入口。未提供的要素不製造數值、頁面、譜面或假曲線。來源聲明不等於獨立驗證。

支持旋律(MIDI音高)、節奏(events/bar)、和聲(標注)、力度／響度(明確單位)、速度(BPM)、調式(標注)、曲式(標注)、織體(聲部數)、音色(標注)、演奏法(標注)。MIDI velocity、dBFS、dB SPL、sone各有自己的含義，不互換成一個「響度」。資料必須在同一觀測時間對齊；回放一起平移合法對齊的時鐘，保留原始時間。

2026-10-11 新增 Yang 2007 音樂研究案例的播放、演奏蠕蟲及播放期腦電配對。音樂來源的速度、相對振幅及拍點間隔和腦電指數保持獨立；見[音樂整合方法](MUSIC-FUSION.html)。這沒有建立EEG→旋律／和聲的已驗證映射。一般參數映射／聲化是一種设计方法，需要明示資料維度、轉換與評估；不能單憑把數據映射到藝術参数就證明生理機制或療效。[3] 原有課件創作方案仍屬創作意圖，保留在折疊區，與觀測值分開。

## 6. 視覺與交互

網格是方形坐標參考，不是腦連接、旋律音網或解剖結構。按用戶最新確認，三頁共用深石墨背景、青灰軌跡、左側采集導航與標題欄；不以色彩標示健康等級。主圖保留來源、三項讀數、窗口與觀察操作；資料入口位於共同側欄，依據與公式放入折疊說明。Canvas與保存圖片使用同一組色彩。

不需要自動鏡頭、轉球或粒子動畫；時間方盒可由用戶拖动轉向；變化只由樣本與用戶操作觸發。鍵盤可操作模式、窗口、時間游標、音樂要素、圖片保存與專注顯示，Escape離開專注顯示。遵循減少非必要動態的可達性方向，[4] 不宣稱僅靠幾項測試已符合完整WCAG。

返回「實時」時由既有連接處理器重新連接已校驗接口；在運行的同一模式不重複建立連接。長來源編號、單位與方法在側欄自然換行。保存圖片按實際寬度排布全部說明，包含來源與資料狀態、觀測時間、必要的原始／回放時間、指數、RMS、樣本窗口及顯示參照。圖片的光點表示記錄時的觀測或明示合成資料，不替代原始記錄。

新增全域0–100、精細50點與細微25點觀察尺度。這只改變可見坐標窗口，真實數值、原始記錄及品質門檻不變。來源提供指數欄位時鐘時按欄位時鐘去重，原始波形計數前進不冒充指數更新。蠕蟲的指數點保留字段時間和封包時間，原始RMS仍使用獨立原始波形時鐘。

自動測試檢查公式、來源邊界、斷段、回放、保存和模擬視口；不能替代實體EEG接入、電極接觸、USB/BLE重連、實體拓展屏幕、個體心理量表或自主神經指標的實驗驗證。圖形可用不等於心理／臨床效度成立。本頁不宣稱診斷、治療效果或「百分百無問題」。
