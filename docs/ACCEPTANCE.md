# 验证方法

## 自动检查

```bash
npm test
npm run build
```

测试覆盖输入范围、缺值、过期、计数停止、乱序、连接重试、
音乐映射、贪吃蛇停止、独立生理通道、启动配置以及静态服务边界。

## 浏览器检查

1. 全新打开页面：动态示范自动运行，轨迹和频段有曲线。
2. 关闭自动变化：两个滑杆直接控制数值及位置。
3. 切换贪吃蛇：目标与当前两个指数对应。
4. 声音需手动开启，暂停和切换来源后停止。
5. 记录、导出JSON／CSV、导入JSON回放。
6. 接入可控的WebSocket测试流，检查断流与重连。
7. 用390px手机宽度及桌面宽度检查溢出与触控操作。
8. 默认示范不请求设备接口或本机程序状态。

## 独立性

用全新clone的副本执行上述命令，副本运行只依赖自身文件和Node。
端口与主机地址可由CLI或环境变量指定。
静态发布产物只包括前端与公开说明，不包含本机记忆和适配器。

浏览器尺寸测试不等于所有真实手机、USB/BLE设备均已验收；
新设备的驱动和数据网关需要按其实际环境验证。
