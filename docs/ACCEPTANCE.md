# 本地整合驗收：v0.2

核驗日期：2026-10-06。

## 已驗證

- 17 項 Node 測試：有效/無效指數、0 值、NaN、範圍、過期、
  裝置封包無進展、亂序、USB 比值、重連與手動停止、記錄格式、
  十參數確定性和貪吃蛇失效停止。
- 新增非 EEG 獨立新鮮度、過期、無效血氧與脈率、
  缺少 HRV、程序查詢併發合併與主服務離線狀態驗證。
- Windows Edge 實際頁面，1500px 桌面與 390px 手機寬度，
  無水平溢出、無 JavaScript 例外。
- 初始無資料不填數字，聲音按鈕不可用。
- 受控 WebSocket 測試流：62/74 指数与 78 BPM 映射同步。
- 已連線但封包沒有進展，3 秒後停止互動；不是只檢查 socket 心跳。
- USB β/α、θ/α 比值只作比值顯示，指數空白。
- 記錄並導出 JSON/CSV；匯入、暫停、續播與結束清空讀數。
- MUST 紫白與 SHCM 藍白切換；同一資料鏈路。
- 低刺激軌跡；reduced-motion 降低繪製頻率，蛇改為跳點以保留資料互動。
- 靜態構建只複製 index/src/public/docs，PowerShell 工具解析通過。
- 專案採 MIT 授權公開，已確認匿名 GitHub API 可讀取源碼和授權。
  GitHub Pages 首次部署成功、匿名 HTTP 200；主庫 main 更新自動發布。
- 統一啟動器加入控制台；精確比對 Node 執行檔與 serve.mjs 參數。
- 統一停止器已實测只停止本控制台並釋放 8767，然後正常重新啟動。
- 實際啟動主服務，8001/8002、5531/5534 均由本主服務持有，
  WebSocket 實測經控制台同源代理自動接收真實主服務快照。
- 九個清單元件（core/console/max/arena/mumu/image/graph/map/visual）
  的程序與所需端口確認就緒。手機橋接、重連守護亦已啟動；
  Ollama 本機報告服務接口可讀取。
- 修正 Processing exe 轉交私有 Java 後的誤判；核對 Java 路徑、
  正確入口類與 JAR，拒絕錯誤 JAR 的模擬身分。
- 受控資料驗證 EEG、SpO2、PR、HRV、GSR 和 Gamma 顯示及匯出，
  壞 EEG 不隱藏有效血氧、斷線自動恢復、手動停止取消重連。
