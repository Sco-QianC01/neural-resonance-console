# 驗收

```sh
npm test
npm run build
```

檢查三個介面：

1. 首頁四頻段動態示範立即可見，不探測私人接口。
2. 切換神經蠕蟲，資料計數繼續；軌跡採收到的樣本。
3. 十項卡片沒有預置造型。僅有EEG時所有音樂值缺失；有音樂觀測時需來源、方法、單位及匹配時間。
4. 設備頁區分瀏覽器能力與已建立的硬體連線。
5. 記錄後可下载JSON／CSV、回放、匯入／匯出設定。
6. 實時來源停止計數時不繼續游走，不自動生成替代資料。
7. 三個手機介面沒有橫向溢出；減少動效時停止非資料動畫。
8. 未經使用者操作，不上傳、配對或選擇設備。

USB／BLE 實機與真實遠端保存需另外驗收；協議測試流不能替代實機證據。

v0.10新增：核對頁內來源鏈接、原始點預設、恒定輸入不移動、線性軌跡標準距離、記錄／回放來源保留及摘要不補造音樂要素。
