# 数据标注与提示词运行说明

当前流程完全在浏览器内执行：人工音乐标签 → 固定规则 → Prompt／JSON。无需Ollama、语言模型权重、音源或8771独立服务。

## 主控制台

按原有方式启动本机采集控制台，打开 `http://127.0.0.1:8767/#annotation`。页面位于既有静态目录 `neural-worm/music-prompt/`，直接使用 `index.html` 文件地址，未修改设备网关或采集代码，无需为此重启采集器。

## 只运行规则页面

使用项目已有Node环境：

```sh
npm start
```

打开默认地址 `http://127.0.0.1:5173/#annotation`，或同源 `/neural-worm/music-prompt/index.html`。这一路径只用于界面和规则生成，不提供硬件采集。

静态构建：

```sh
npm run build
```

将 `dist` 作为网站根目录，通过HTTP本机入口或HTTPS提供。保留 `neural-worm/`、`src/`及 `public/` 的相对目录。不支持直接双击 `file://` 页面加载模块；浏览器需要正常的模块、fetch与SHA-256支持。无需为本模块关闭Mac系统保护或安装系统级驱动。

## 数据与服务边界

- JSON及人工标注在页面内处理；仅主动点击下载／复制时交付结果。
- 页面只请求自己的标签目录、JS/CSS及主动选取的已有速度标注；不请求模型健康、标签编排、音乐生成或谱面渲染接口。
- 后端历史Ollama接口仍可能存在，供历史工作流保留。当前页面不调用；不为改页面而删除权重、修改全局配置或停止其他服务。
- 原生旧发行包不会随源码自动更新。Mac／Windows实际安装包与硬件接入须分别验收。
