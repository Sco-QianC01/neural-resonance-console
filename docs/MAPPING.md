# 从输入到互动与音乐

## 二维位置

专注度和放松度均为来源提供的0–100指数：

```text
A = 专注度 / 100
R = 放松度 / 100
X = A
Y = 1 - R
```

轨迹随当前有效样本变化。贪吃蛇追随同一目标点，不反向改变输入。
频段比值不当成百分制指数；没有有效指数时只显示已有的频段。

## 十项参数

令 `E = 0.65A + 0.35(1-R)`。当前规则版本是`eeg-music-rules-v1`。

| 参数 | 规则 |
| --- | --- |
| 速度 | 最低BPM + (最高−最低) × E |
| 节奏密度 | 1 + 8A |
| 音高中心 | 48 + 24A，MIDI |
| 音域 | 7 + 17A，半音 |
| 力度 | 32 + 58E |
| 音色明亮度 | 15 + 70E，% |
| 和声张力 | 10 + 55(1−R)，% |
| 发音长度 | 30 + 60R，% |
| 空间宽度 | 25 + 65R，% |
| 过渡时间 | 1 + 7R，秒 |

可以在界面修改最低和最高速度，或在`src/music.mjs`替换规则。
参数是可追溯的工程映射，不宣称是已校准的心理测量模型。

## 输入失效

3秒没有新样本、来源计数不再增长、接触不良或指数无效时，
不产生新位置和音乐参数，已开启的声音停止。
示范、实测和回放保留不同的来源标记。

## 声音与记录

声音是需要手动开启的低音量正弦预览，目前使用音高与力度，
尚未合成完整乐曲或应用全部十项参数。
切换来源、断线或隐藏页面时静音。

JSON导出保留输入、时间、来源、对应音乐参数和操作记录；
CSV适合表格分析。可选生理通道缺少时保留null，不补零。
回放保留时间差与缺口，单次最多20000样本，导入不超过20MB。

输入协议见[DATA-INPUT.md](DATA-INPUT.md)。
