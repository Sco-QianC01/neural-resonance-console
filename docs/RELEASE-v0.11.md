# v0.11 · 展示仪器与来源方案

- 三个入口改为左侧导航，窄屏使用可展开侧栏。
- 波形、神经蠕虫和设备设置保留共享数据流；展示模式只放大神经蠕虫，不改变测量。
- 十要素改为课件第17–20页的四套创作方案。没有真实音乐观测时不显示观测数值，不用随机回退。
- 创作意图与`musicFeatures`来源观测分离保存，JSON、CSV与交接摘要同时保留两者；回放采用当时保存的方案。
- 神经蠕虫绘图区使用等比例坐标，不拉伸轨迹；暂停、断流和来源切换都保留真实时序。
- 设备设置支持保存USB VID/PID、序列号、位置，以及BLE地址／macOS UUID；COM号变化后按设备身份重识别。
- Windows启动器增加`-SetupOnly`、macOS启动器增加`--setup-only`环境检查入口。首次安装仍由官方uv与锁定依赖完成，系统权限和厂商驱动按系统提示处理。

研究边界与课件逐页对应见[十要素创作方案](MUSIC-PLANS.md)和[证据文件](EVIDENCE.md)。
